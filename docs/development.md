# Website Development

This document describes the development and publishing workflow for the esenus website maintained in the `www` repository.

## Publishing

The website is published using GitHub Pages.

The exact build and deployment configuration must be confirmed from the repository settings, workflow files, and current source code.

## Repository Scope

The `www` repository contains:

- The esenus website
- Public-facing information about esenus
- Public-facing introductions to Loom, Nest, and Muse
- Documentation related to this website's development and publishing

Internal design documents and implementation details for Loom, Muse, and Nest belong in their respective repositories.

## Changes

Changes to the website should be made in a way that allows them to be reviewed before they are published.

The repository's current branch rules, pull request process, and deployment workflow should be confirmed before documenting them as established procedures.

## Verification

Before publishing a change, verify the relevant behavior and appearance of the website.

Depending on the change, this may include:

- Checking the page structure and content
- Checking the layout at different viewport sizes
- Checking light and dark color schemes, where supported
- Checking links and navigation
- Confirming that the published site reflects the intended change
