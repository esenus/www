# Projects

esenus consists of independent Projects, each with a distinct role.

They are not intended to be combined into a single application or navigation structure. Each Project serves its own purpose while allowing information and outcomes to connect across activities.

## Loom

**Role:** Web Publishing Platform

**Catchphrase:** Shape your space.

Loom provides a way to create websites, structure information, and publish the result.

It turns a space for information into a form that can be built and shared.

## Nest

**Role:** Personal Systems

**Catchphrase:** Make life work.

Nest provides personal systems for organizing daily information and activities and shaping systems around individual needs.

It helps make everyday life work in a way that suits the person using it.

## Muse

**Role:** Studio Journal

**Catchphrase:** Ideas in motion.

Muse presents activities, making, experiments, and thoughts, along with the things that emerge from them.

It includes finished work as well as ongoing activities, works in progress, and ideas still taking shape.

## How They Relate

Loom, Muse, and Nest have different responsibilities:

- **Loom** — Create and publish websites.
- **Nest** — Organize and use personal information.
- **Muse** — Present activities and what emerges from them.

Each Project can develop independently. Information, work, and ideas may connect them, but this does not imply a shared application or a single system architecture.

## Development

Each Project maintains its own design documents, implementation, and development process.

The detailed specifications for each Project are maintained in its own repository. This repository provides only a public-facing overview.
